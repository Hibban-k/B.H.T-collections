# B.H.T-collections (Blanket House Trading L.L.C. Dubai)

Premium home textiles, blankets, bed linen, and commercial trading solutions established in Dubai in 2009, serving 500+ clients across 6 GCC countries.

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Database**: MongoDB (Mongoose)
